# Welcome to the Machine Monitoring Dashboard

This site helps track **daily machine and staff attendance** with two main tools:

- [Input Page](/input) → Submit attendance and machine status records.
- [Summary Page](/summary) → View reports, summaries, and location‑specific breakdowns.

---

## 📊 How It Works
1. **Input**: Staff enter attendance or machine status using the form.
2. **Storage**: Records are saved in Airtable.
3. **Summary**: Reports are generated and displayed here, filterable by date and location.
